# Admin: «Προσωπικό» (Staff, removed)

In version 1.8.0 the **«Προσωπικό»** (staff) tab was merged into **«Σήμερα»** (today).
Every employee is now a row in «Σήμερα», with the same **«Ενέργειες ▾»** (actions) menu
(leave, overtime, PIN, QR card, rename, deactivate, delete and so on); inactive employees
are under «Ανενεργοί (N)» at the bottom.

- The menu and its actions: [Today → The «Ενέργειες» menu](Admin-Today-EN#the-ενέργειες-menu)
- What each employee's row shows: [Today → What each row shows](Admin-Today-EN#what-each-row-shows)
- Adding employees: [Today → Adding employees](Admin-Today-EN#adding-employees)
- Flexible arrival is now set on the schedule card:
  [Schedules and holidays → Flexible arrival](Admin-Schedules-and-Holidays-EN#flexible-arrival-ευέλικτη-προσέλευση)
