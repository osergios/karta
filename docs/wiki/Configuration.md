# Ρυθμίσεις server (`.env`)

Όλες οι ρυθμίσεις του server βρίσκονται στο αρχείο `.env` (ξεκινήστε από το
`.env.example`). Μετά από κάθε αλλαγή, επανεκκινήστε την εφαρμογή. **Μην ανεβάσετε ποτέ
το πραγματικό σας `.env` στο GitHub**: περιέχει τον κωδικό του ΕΡΓΑΝΗ και κλειδιά.

Οι κανόνες της καθημερινής λειτουργίας, όπως ευελιξία, προθεσμία υπερωρίας και
εβδομαδιαία όρια, **δεν** ρυθμίζονται εδώ. Βρίσκονται στη σελίδα διαχείρισης, στο
[«Ρυθμίσεις» → «Όρια και ειδοποιήσεις»](Admin-Settings).

## ΕΡΓΑΝΗ

| Μεταβλητή | Υποχρεωτική | Τι σημαίνει |
|---|---|---|
| `ERGANI_MODE` | ναι | `dry_run`, `trial` ή `production`. Δείτε [Έναρξη κανονικής λειτουργίας](Going-Live). Η διεύθυνση του ΕΡΓΑΝΗ προκύπτει από τη λειτουργία· μην τη ρυθμίσετε μόνοι σας. |
| `ERGANI_USERNAME` / `ERGANI_PASSWORD` | για `production` (και για να φέρετε το προσωπικό) | Ο χρήστης web services της επιχείρησης στο ΕΡΓΑΝΗ. |
| `ERGANI_USER_TYPE` | όχι (προεπιλογή `01`) | `01` = χρήστης API / εξωτερικός χρήστης, `02` = χρήστης «ΕΡΓΑΝΗ» από τους «Εξωτερικούς Χρήστες Παραρτημάτων». |
| `ERGANI_TRIAL_USERNAME` / `ERGANI_TRIAL_PASSWORD` | για `trial` | Χρήστης του δοκιμαστικού περιβάλλοντος του ΕΡΓΑΝΗ (`trialv2eservices.yeka.gr`, σύνδεση με TaxisNet του εργοδότη). |
| `ERGANI_TRIAL_USER_TYPE` | όχι (προεπιλογή `02`) | Όπως παραπάνω, για τον δοκιμαστικό χρήστη. |
| `EMPLOYER_AFM` | ναι | Το ΑΦΜ του εργοδότη (9 ψηφία). |
| `BRANCH_NUMBER` | όχι (προεπιλογή `0`) | Ο αριθμός παραρτήματος (Α/Α παραρτήματος). |
| `ERGANI_EMPLOYER_ID` | όχι | Ο κωδικός σας μέσα στο QR εργαζομένου του ΕΡΓΑΝΗ (το `id:`). Όταν οριστεί, η οθόνη του καταστήματος δεν δέχεται QR ΕΡΓΑΝΗ άλλου εργοδότη. |

> Στο `dry_run` δεν υποβάλλεται ποτέ τίποτα. Οι υπηρεσίες **ανάγνωσης** που χρησιμοποιεί
> ο «Έλεγχος ΕΡΓΑΝΗ» (εργοδότης, παραρτήματα, προσωπικό) χρησιμοποιούν ωστόσο το
> πραγματικό ΕΡΓΑΝΗ, μόνο για ανάγνωση. Άρα χρειάζεστε τον πραγματικό χρήστη για να φέρετε
> το προσωπικό, ακόμα και στις δοκιμές.

## Πρόσβαση διαχειριστή (Cloudflare Access)

| Μεταβλητή | Υποχρεωτική | Τι σημαίνει |
|---|---|---|
| `CF_ACCESS_TEAM_DOMAIN` | ναι | Το team domain σας στο Cloudflare Zero Trust, χωρίς `https://`, π.χ. `yourteam.cloudflareaccess.com`. |
| `CF_ACCESS_AUD` | ναι | Το Audience (AUD) tag της εφαρμογής Access που προστατεύει το `/admin`. |
| `ADMIN_EMAILS` | ναι | Τα email που επιτρέπεται να μπουν στη σελίδα διαχείρισης, χωρισμένα με κόμμα. Πρέπει να ταιριάζουν με την πολιτική του Access. |

## Εφαρμογή

| Μεταβλητή | Προεπιλογή | Τι σημαίνει |
|---|---|---|
| `PUBLIC_ORIGIN` | `http://localhost:8000` | Η δημόσια διεύθυνση της Karta σας, π.χ. `https://karta.tokatastimamou.gr`. Χρησιμοποιείται για να ελέγχεται από πού έρχονται τα αιτήματα και για τους συνδέσμους κάρτας στο κινητό. **Ορίστε την στην κανονική λειτουργία.** |
| `DB_PATH` | `/data/workcard.db` | Η θέση της βάσης SQLite. |
| `LATE_THRESHOLD_SECONDS` | `120` | Αν ένα χτύπημα φτάσει στο ΕΡΓΑΝΗ αργότερα από τόσα δευτερόλεπτα μετά τη στιγμή που έγινε (π.χ. μετά από διακοπή του internet), στέλνεται ως εκπρόθεσμη δήλωση με αιτιολογία. Δείτε [Πώς φτάνουν τα χτυπήματα στο ΕΡΓΑΝΗ](Ergani-Submissions). |
| `DEBOUNCE_SECONDS` | `60` | Ελάχιστος χρόνος ανάμεσα σε δύο χτυπήματα του ίδιου ατόμου, ώστε να μη γίνονται κατά λάθος διπλά. |

## Ειδοποιήσεις στο κινητό (προαιρετικά)

Η Karta στέλνει ειδοποιήσεις στο κινητό σας μέσω του [ntfy](https://ntfy.sh): εγκαταστήστε
την εφαρμογή ntfy και εγγραφείτε στο θέμα (topic) σας. Αν τα αφήσετε κενά, οι ειδοποιήσεις
στο κινητό απενεργοποιούνται και εμφανίζονται μόνο στη σελίδα διαχείρισης.

| Μεταβλητή | Τι σημαίνει |
|---|---|
| `NTFY_URL` | Ο server του ntfy, π.χ. `https://ntfy.sh` ή δικός σας. |
| `NTFY_TOPIC` | Το όνομα του θέματος. Αν χρησιμοποιείτε τον δημόσιο server, διαλέξτε κάτι μακρύ και τυχαίο. |
| `NTFY_TOKEN` | Κλειδί πρόσβασης, αν το ζητά ο server σας. |

## Προβολή PIN (προαιρετικά)

| Μεταβλητή | Τι σημαίνει |
|---|---|
| `PIN_KEY` | Κλειδί 32 bytes που επιτρέπει στη σελίδα διαχείρισης να δείχνει τα τρέχοντα PIN των εργαζομένων. Δημιουργήστε το μία φορά με `python3 -c "import os,base64;print(base64.urlsafe_b64encode(os.urandom(32)).decode())"`. |

Χωρίς `PIN_KEY`, τα PIN αποθηκεύονται μόνο ως μη αναστρέψιμη σύνοψη (hash) και δεν
μπορούν να εμφανιστούν ξανά· μπορείτε μόνο να ορίσετε νέο. Αν χάσετε το κλειδί, τα PIN
συνεχίζουν να λειτουργούν, αλλά δεν εμφανίζονται μέχρι να δώσετε σε κάθε εργαζόμενο νέο
PIN («Νέο PIN»).
