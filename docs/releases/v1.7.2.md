## Karta 1.7.2: ο κωδικός κρυπτογράφησης δεν ξεχνιέται

### Βελτιώσεις

- **Ο κωδικός κρυπτογράφησης των αντιγράφων στο cloud τονίζεται όπως πρέπει.** Δεν ανακτάται
  με κανέναν τρόπο: ούτε η Karta, ούτε η Google / Dropbox / Backblaze μπορούν να ανοίξουν τα
  αντίγραφα χωρίς αυτόν. Το πλαίσιο του κωδικού το λέει καθαρά, έχει κουμπί «Αντιγραφή», και
  κλείνει μόνο αφού γράψετε τους 4 τελευταίους χαρακτήρες του.
- **«Εμφάνιση κωδικού κρυπτογράφησης»** στις «Ρυθμίσεις» → «Αντίγραφα ασφαλείας»: όσο
  δουλεύει το μηχάνημα, ξαναδείχνει τον κωδικό, αν δεν τον γράψατε την πρώτη φορά. Γράψτε τον
  τώρα: όταν χαλάσει το μηχάνημα, μένει μόνο ό,τι έχετε γράψει.

## Αναβάθμιση

- Από τη σελίδα διαχείρισης («Ενημέρωση τώρα») ή `./setup.sh update`. Τίποτα άλλο.
- Βάση δεδομένων: χωρίς αλλαγές.
- Επιστροφή σε προηγούμενη έκδοση: ασφαλής.

## Karta 1.7.2: an encryption password you can't miss

### Improvements

- **The cloud backups' encryption password gets the emphasis it needs.** It can't be recovered
  in any way: neither Karta nor Google / Dropbox / Backblaze can open the backups without it.
  The password box says so plainly, has a «Αντιγραφή» (copy) button, and closes only after you
  type its last 4 characters.
- **«Εμφάνιση κωδικού κρυπτογράφησης»** (show the encryption password) in «Ρυθμίσεις» →
  «Αντίγραφα ασφαλείας»: while the machine works, it shows the password again, if you didn't
  write it down the first time. Write it down now: once the machine breaks, only what you
  wrote down is left.

## Upgrading

- From the admin page («Ενημέρωση τώρα») or `./setup.sh update`. Nothing else.
- Database: no changes.
- Going back to the previous version: safe.
