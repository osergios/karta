## Karta 1.0.1

### Διόρθωση

- **Νέες εγκαταστάσεις με Docker:** με ένα καινούργιο volume Docker, η Karta δεν μπορούσε
  να δημιουργήσει τη βάση της και σταματούσε στην εκκίνηση («unable to open database
  file»). Το image φτιάχνει πλέον τον φάκελο `/data` με τα σωστά δικαιώματα. Οι
  υπάρχουσες εγκαταστάσεις δεν επηρεάζονται.

### Νέα

- **[Εύκολη εγκατάσταση, βήμα προς βήμα](https://github.com/osergios/karta/wiki/Easy-Installation)**
  για όσους δεν είναι προγραμματιστές: Raspberry Pi, παλιό PC ή δωρεάν cloud, με Cloudflare
  Tunnel (HTTPS χωρίς ρυθμίσεις στο router) και αυτόματα αντίγραφα ασφαλείας.
- **`docker-compose.yml`** έτοιμο για Karta + Cloudflare Tunnel.
- **Αυτόματα τεστ** (83) σε κάθε αλλαγή, μαζί με έλεγχο ότι το image ξεκινά.

### Ενημέρωση

```bash
docker compose pull && docker compose up -d
```

ή `docker pull ghcr.io/osergios/karta:1.0.1`.

## Karta 1.0.1

### Fix

- **New Docker installations:** with a brand‑new Docker volume, Karta couldn't create its
  database and stopped at start‑up ("unable to open database file"). The image now creates
  the `/data` folder with the right permissions. Existing installations aren't affected.

### New

- **[Easy step‑by‑step installation](https://github.com/osergios/karta/wiki/Easy-Installation-EN)**
  for non‑programmers: Raspberry Pi, an old PC or a free cloud machine, with Cloudflare
  Tunnel (HTTPS without router settings) and automatic backups.
- **`docker-compose.yml`** ready for Karta + Cloudflare Tunnel.
- **Automated tests** (83) on every change, including a check that the image starts.

### Updating

```bash
docker compose pull && docker compose up -d
```

or `docker pull ghcr.io/osergios/karta:1.0.1`.
