## Karta 1.8.3: δεύτερη εγκατάσταση χωρίς να πειράζει την πρώτη

### Διόρθωση

- **Ο οδηγός ρύθμισης (`./setup.sh`) δεν παίρνει πια το tunnel άλλης εγκατάστασης.** Αν στον
  ίδιο λογαριασμό Cloudflare υπάρχει ήδη η Karta σε άλλη διεύθυνση (π.χ. ένα δεύτερο κατάστημα
  ή ένα μηχάνημα για δοκιμές), ο οδηγός χρησιμοποιούσε το ίδιο tunnel «karta» και η πρώτη
  διεύθυνση σταματούσε να λειτουργεί. Τώρα η νέα εγκατάσταση παίρνει δικό της tunnel. Νέο
  μηχάνημα στην **ίδια** διεύθυνση (ανάκτηση μετά από καταστροφή) συνεχίζει με το υπάρχον tunnel,
  όπως πριν.
- Οι εγκαταστάσεις που ήδη δουλεύουν δεν επηρεάζονται.

## Αναβάθμιση

- Από τη σελίδα διαχείρισης («Ενημέρωση τώρα») ή `./setup.sh update`. Τίποτα άλλο.
- Βάση δεδομένων: χωρίς αλλαγές.
- Επιστροφή σε προηγούμενη έκδοση: ασφαλής.

## Karta 1.8.3: a second installation leaves the first one alone

### Fix

- **The setup assistant (`./setup.sh`) no longer takes another installation's tunnel.** If the
  same Cloudflare account already had Karta on another address (e.g. a second shop or a test
  machine), the assistant used the same tunnel «karta» and the first address stopped working.
  Now the new installation gets a tunnel of its own. A new machine on the **same** address
  (disaster recovery) carries on with the existing tunnel, as before.
- Installations that already work are not affected.

## Upgrading

- From the admin page («Ενημέρωση τώρα») or `./setup.sh update`. Nothing else.
- Database: no changes.
- Going back to an earlier version: safe.
