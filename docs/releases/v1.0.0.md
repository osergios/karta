## Karta 1.0.0: η πρώτη δημόσια έκδοση

Η **Karta** είναι ψηφιακή κάρτα εργασίας για μικρές επιχειρήσεις, που την εγκαθιστάτε στον
δικό σας server. Οι εργαζόμενοι χτυπούν κάρτα στην οθόνη του καταστήματος με PIN ή QR, και
η Karta στέλνει κάθε προσέλευση και αποχώρηση στο **ΕΡΓΑΝΗ ΙΙ**.

### Τι περιλαμβάνει

- **Οθόνη καταστήματος:** PIN, κάρτες QR του καταστήματος και το προσωπικό QR του ΕΡΓΑΝΗ /
  myErgani· υπενθυμίσεις με ήχο· προστασίες για νωρίτερη προσέλευση, κλειστές ημέρες και
  διπλά χτυπήματα.
- **Αποστολή στο ΕΡΓΑΝΗ:** ουρά με επαναλήψεις, εκπρόθεσμες δηλώσεις με τον σωστό κωδικό,
  και ασφαλής χειρισμός αβέβαιων υποβολών ώστε να μη δηλωθεί ποτέ κάτι δύο φορές.
- **Σελίδα διαχείρισης:** σήμερα, προσωπικό, ωράρια με ιστορικό, άδειες, υπερωρίες,
  ευέλικτη προσέλευση, αργίες και κλεισίματα, συσκευές, κινήσεις.
- **Αναφορές Excel** για τον λογιστή (μηνιαίες και ετήσιες), με τις απολογιστικές
  δηλώσεις που πρέπει να γίνουν.
- **Λειτουργίες δοκιμής:** `dry_run`, `trial`, λειτουργία εκπαίδευσης και περίοδος
  προσαρμογής.
- **Ειδοποιήσεις στο κινητό** μέσω ntfy.

### Εγκατάσταση

Έτοιμο image Docker (amd64 και arm64, π.χ. Raspberry Pi):

```bash
docker pull ghcr.io/osergios/karta:1.0.0
```

Πλήρεις οδηγίες στο [wiki](https://github.com/osergios/karta/wiki/Installation).

## Karta 1.0.0: the first public release

**Karta** is a self‑hosted digital work card for small Greek businesses. Staff clock in and
out on a shop screen with a PIN or QR code, and Karta sends every arrival and departure to
**Ergani II**.

### What's included

- **Shop screen:** PIN, the shop's QR cards and the personal Ergani / myErgani QR; reminders
  with sound; safeguards against early arrivals, closed days and double punches.
- **Ergani submission:** a queue with retries, late declarations with the right code, and
  safe handling of uncertain submissions so nothing is ever declared twice.
- **Admin page:** today, staff, schedules with history, leave, overtime, flexible arrival,
  holidays and closures, devices, movements.
- **Excel reports** for the accountant (monthly and yearly), including the retrospective
  declarations to file.
- **Safe ways to test:** `dry_run`, `trial`, training mode and an onboarding period.
- **Phone alerts** through ntfy.

### Installation

Ready‑made Docker image (amd64 and arm64, e.g. Raspberry Pi):

```bash
docker pull ghcr.io/osergios/karta:1.0.0
```

Full instructions in the [wiki](https://github.com/osergios/karta/wiki/Installation-EN).
