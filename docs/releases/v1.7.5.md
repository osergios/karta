## Karta 1.7.5: ασφαλής ανάκτηση σε νέο μηχάνημα

### Διορθώσεις

- **Ένα νέο μηχάνημα δεν ανεβάζει πια την άδεια βάση του πάνω από τα αντίγραφα.** Όταν μια
  νέα εγκατάσταση συνδεόταν στα υπάρχοντα αντίγραφα του cloud για να τα επαναφέρει, ανέβαζε
  αμέσως αντίγραφο της άδειας βάσης της· αυτό γινόταν το πιο πρόσφατο στη λίστα της
  επαναφοράς. Τώρα δεν ανεβαίνει αντίγραφο όσο η βάση δεν έχει εργαζόμενους. Το ίδιο και για
  το νυχτερινό αντίγραφο στο μηχάνημα και στο USB, σε κάθε νέα εγκατάσταση.

### Νέα σελίδα στο wiki

- **[Ανάκτηση μετά από καταστροφή](https://github.com/osergios/karta/wiki/Disaster-Recovery):**
  βήμα προς βήμα, αν χαθεί το VPS ή το μηχάνημα του καταστήματος, με τον κωδικό
  κρυπτογράφησης. Τυπώστε τη και φυλάξτε τη μαζί με τον κωδικό.

## Αναβάθμιση

- Από τη σελίδα διαχείρισης («Ενημέρωση τώρα») ή `./setup.sh update`. Τίποτα άλλο.
- Βάση δεδομένων: χωρίς αλλαγές.
- Επιστροφή σε προηγούμενη έκδοση: ασφαλής.

## Karta 1.7.5: safe recovery on a new machine

### Fixes

- **A new machine no longer uploads its empty database over the backups.** When a new
  installation connected to the existing cloud backups to restore them, it immediately
  uploaded a copy of its empty database, which became the newest one in the restore list.
  Now nothing is uploaded while the database has no employees. The same goes for the nightly
  copy on the machine and the USB, on every new installation.

### New wiki page

- **[Disaster recovery](https://github.com/osergios/karta/wiki/Disaster-Recovery-EN):** step by
  step, if the VPS or the shop machine is lost, with the encryption password. Print it and keep
  it with the password.

## Upgrading

- From the admin page («Ενημέρωση τώρα») or `./setup.sh update`. Nothing else.
- Database: no changes.
- Going back to the previous version: safe.
