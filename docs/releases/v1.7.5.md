## Karta 1.7.5: πλήρης ανάκτηση σε νέο μηχάνημα με έναν μόνο κωδικό

### Διορθώσεις

- **Ένα νέο μηχάνημα δεν ανεβάζει πια την άδεια βάση του πάνω από τα αντίγραφα.** Όταν μια
  νέα εγκατάσταση συνδεόταν στα υπάρχοντα αντίγραφα του cloud για να τα επαναφέρει, ανέβαζε
  αμέσως αντίγραφο της άδειας βάσης της· αυτό γινόταν το πιο πρόσφατο στη λίστα της
  επαναφοράς. Τώρα δεν ανεβαίνει αντίγραφο όσο η βάση δεν έχει εργαζόμενους. Το ίδιο και για
  το νυχτερινό αντίγραφο στο μηχάνημα και στο USB, σε κάθε νέα εγκατάσταση.

- **Η επαναφορά από το cloud φέρνει πίσω και το κλειδί των κωδικών (`PIN_KEY`).** Το κλειδί με
  το οποίο είναι κλειδωμένοι ο κωδικός ΕΡΓΑΝΗ, τα PIN και οι κάρτες QR ταξιδεύει πλέον
  κρυπτογραφημένο μέσα σε κάθε αντίγραφο στο cloud. Σε νέο μηχάνημα η Karta το χρησιμοποιεί
  αυτόματα: τίποτα δεν χρειάζεται να ξαναγραφτεί. Αρκεί ο κωδικός κρυπτογράφησης.

- **Πιο γρήγορο νυχτερινό αντίγραφο στο cloud.** Το καθάρισμα των παλιών αντιγράφων, που στο
  Google Drive κρατά λεπτά, γίνεται πλέον μία φορά την εβδομάδα αντί για κάθε βράδυ· κρατιούνται
  τα ίδια αντίγραφα. Ό,τι σβήνεται από το Google Drive δεν πάει πια στον κάδο.
- Δίπλα στο αποτέλεσμα του αντιγράφου φαίνεται **πόσο κράτησε**, π.χ. «07/10 23:41 ✓ (1′20″)».

### Νέα σελίδα στο wiki

- **[Ανάκτηση μετά από καταστροφή](https://github.com/osergios/karta/wiki/Disaster-Recovery):**
  βήμα προς βήμα, αν χαθεί το VPS ή το μηχάνημα του καταστήματος, με μόνο τον
  κωδικό κρυπτογράφησης. Τυπώστε τη και φυλάξτε τη μαζί με τον κωδικό.

## Αναβάθμιση

- Από τη σελίδα διαχείρισης («Ενημέρωση τώρα») ή `./setup.sh update`. Τίποτα άλλο.
- Βάση δεδομένων: χωρίς αλλαγές.
- Επιστροφή σε προηγούμενη έκδοση: ασφαλής.

## Karta 1.7.5: full recovery on a new machine with one password

### Fixes

- **A new machine no longer uploads its empty database over the backups.** When a new
  installation connected to the existing cloud backups to restore them, it immediately
  uploaded a copy of its empty database, which became the newest one in the restore list.
  Now nothing is uploaded while the database has no employees. The same goes for the nightly
  copy on the machine and the USB, on every new installation.

- **A cloud restore brings back the key of the secrets too (`PIN_KEY`).** The key that locks
  the Ergani password, the PINs and the QR cards now travels encrypted inside every cloud
  backup. On a new machine Karta uses it automatically: nothing has to be typed again. The
  encryption password is all you need.

- **Quicker nightly cloud backup.** Clearing out old backups, which takes minutes on Google
  Drive, now happens once a week instead of every night; the same backups are kept. What is
  deleted from Google Drive no longer goes to the trash.
- Next to the backup result you see **how long it took**, e.g. «07/10 23:41 ✓ (1′20″)».

### New wiki page

- **[Disaster recovery](https://github.com/osergios/karta/wiki/Disaster-Recovery-EN):** step by
  step, if the VPS or the shop machine is lost, with the encryption password. Print it and keep
  it with the password.

## Upgrading

- From the admin page («Ενημέρωση τώρα») or `./setup.sh update`. Nothing else.
- Database: no changes.
- Going back to the previous version: safe.
