## Karta 1.4.1

### Νέο

- **Αποποίηση ευθύνης:** νέο [`DISCLAIMER.md`](https://github.com/osergios/karta/blob/main/DISCLAIMER.md),
  και σύνδεσμος στη σελίδα διαχείρισης («Ρυθμίσεις» → «Έκδοση και ενημέρωση»). Το
  `./setup.sh` ζητά μία φορά να γράψετε «ναι» πριν την εγκατάσταση.

### Βελτιώσεις

- Πιο ακριβείς οδηγίες σε σελίδα διαχείρισης και οδηγό ρύθμισης: η πλήρης διαδρομή
  «Ρυθμίσεις» → «Επιχείρηση και σύνδεση με το ΕΡΓΑΝΗ» → «Λειτουργία», και σωστές οδηγίες
  για τη χειροκίνητη ρύθμιση του Cloudflare.
- Ενημερωμένο wiki: το `PIN_KEY` είναι απαραίτητο, φυλάξτε το `.env` αν το μόνο αντίγραφο
  είναι στο cloud, ειδοποιήσεις αντιγράφων, και η «δωρεάν» επιλογή είναι δικός σας server
  (VPS) με SSH.

### Ενημέρωση

«Ρυθμίσεις» → «Έκδοση και ενημέρωση» → «Ενημέρωση τώρα», ή από το μηχάνημα:

```bash
cd ~/karta
curl -fsSLO https://raw.githubusercontent.com/osergios/karta/main/setup.sh && chmod +x setup.sh
./setup.sh update
```

## Karta 1.4.1

### New

- **Disclaimer:** new [`DISCLAIMER.md`](https://github.com/osergios/karta/blob/main/DISCLAIMER.md),
  linked from the admin page («Ρυθμίσεις» → «Έκδοση και ενημέρωση»). `./setup.sh` asks once
  for «ναι» before installing.

### Improvements

- Clearer directions in the admin page and the setup wizard: the full path
  «Ρυθμίσεις» → «Επιχείρηση και σύνδεση με το ΕΡΓΑΝΗ» → «Λειτουργία», and correct pointers
  for setting up Cloudflare by hand.
- Wiki brought up to date: `PIN_KEY` is required, keep `.env` safe when the only copy is in
  the cloud, backup alerts, and the "free" option is your own server (VPS) reached over SSH.

### Updating

«Ρυθμίσεις» → «Έκδοση και ενημέρωση» → «Ενημέρωση τώρα», or on the machine:

```bash
cd ~/karta
curl -fsSLO https://raw.githubusercontent.com/osergios/karta/main/setup.sh && chmod +x setup.sh
./setup.sh update
```
