## Karta 1.3.0: ενημέρωση με ένα κουμπί

### Νέα

- **«Ενημέρωση τώρα»** στις «Ρυθμίσεις» → «Έκδοση και ενημέρωση»: η σελίδα διαχείρισης δείχνει
  την έκδοση που τρέχει και αν υπάρχει νεότερη (με «Τι αλλάζει»). Με ένα κουμπί γίνεται
  αντίγραφο ασφαλείας, κατεβαίνει η νέα έκδοση και η Karta ξαναξεκινά· η σελίδα και η οθόνη
  του καταστήματος ξαναφορτώνουν μόνες τους. Για ασφάλεια, την ενημέρωση την κάνει ένα μικρό
  πρόγραμμα στο μηχάνημα (`update.sh`), όχι η ίδια η Karta.
- **`./setup.sh update`:** η ίδια ενημέρωση από το τερματικό.

### Ενημέρωση (μία φορά, για να εμφανιστεί το κουμπί)

```bash
cd ~/karta
curl -fsSLO https://raw.githubusercontent.com/osergios/karta/main/setup.sh && chmod +x setup.sh
./setup.sh update
```

Από εδώ και πέρα, οι ενημερώσεις γίνονται από τη σελίδα διαχείρισης.

## Karta 1.3.0: one-button updates

### New

- **«Ενημέρωση τώρα»** (update now) in «Ρυθμίσεις» → «Έκδοση και ενημέρωση»: the admin page
  shows the running version and whether a newer one is out (with "what's new"). One button
  makes a backup, downloads the new version and restarts Karta; the page and the shop screen
  reload by themselves. For security, a small program on the machine (`update.sh`) does the
  update, not Karta itself.
- **`./setup.sh update`:** the same update from the terminal.

### Updating (once, so the button appears)

```bash
cd ~/karta
curl -fsSLO https://raw.githubusercontent.com/osergios/karta/main/setup.sh && chmod +x setup.sh
./setup.sh update
```

From then on, updates happen from the admin page.
