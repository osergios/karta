## Karta 1.2.0: ρυθμίσεις από τη σελίδα διαχείρισης, αντίγραφα για χρόνια

### Νέα

- **Ρυθμίσεις στη σελίδα διαχείρισης** («Ρυθμίσεις» → «Επιχείρηση και σύνδεση με το ΕΡΓΑΝΗ»):
  ΑΦΜ, παράρτημα, χρήστης ΕΡΓΑΝΗ (και χρήστης για το δοκιμαστικό ΕΡΓΑΝΗ) με **«Δοκιμή
  σύνδεσης»**. Ο κωδικός φυλάσσεται κρυπτογραφημένος. Ισχύουν αμέσως, χωρίς επανεκκίνηση.
- **Αλλαγή λειτουργίας** (δοκιμαστική → δοκιμαστικό ΕΡΓΑΝΗ → κανονική) από τη σελίδα
  διαχείρισης, με επιβεβαίωση του ΑΦΜ και δοκιμή σύνδεσης πριν την αλλαγή.
- **Ειδοποιήσεις στο κινητό** (ntfy) από τη σελίδα διαχείρισης, με δοκιμαστική ειδοποίηση.
- **Αντίγραφα ασφαλείας για χρόνια:** κάθε βράδυ 30 ημερήσια, 24 μηνιαία και ένα για κάθε
  έτος. Αντίγραφο **σε USB** (`./setup.sh usb`) ή **κρυπτογραφημένο σε cloud** — Google
  Drive, Dropbox, Backblaze B2 (`./setup.sh cloud`), και **επαναφορά** με
  `./setup.sh restore`. Στη σελίδα διαχείρισης: το αποτέλεσμα κάθε βραδιού, ειδοποίηση αν
  σταματήσουν, **λήψη αντιγράφου** και **«Αρχείο χτυπημάτων»** κάθε έτους σε Excel.
- **Απλούστερος οδηγός ρύθμισης:** ρωτά μόνο διεύθυνση, email διαχειριστών και Cloudflare.

### Διορθώσεις

- Στις ερωτήσεις ναι/όχι, το λατινικό «n» σημαίνει πλέον «όχι».
- Ο οδηγός εγκαθιστά πάντα στο `~/karta` και λέει σε ποιον φάκελο να ξανατρέξει.
- Αν το ΕΡΓΑΝΗ αργεί, ο «Έλεγχος ΕΡΓΑΝΗ» σταματά σε 60″ με σαφές μήνυμα, αντί για «Σφάλμα
  524». Τα σφάλματα του Cloudflare εξηγούνται στα ελληνικά.
- Στα «Ωράρια»: το ΕΡΓΑΝΗ συνήθως δίνει μόνο τις ώρες την εβδομάδα, οπότε το ωράριο κάθε
  ημέρας γράφεται από το πρόγραμμα του λογιστή.

### Ενημέρωση

```bash
cd ~/karta
curl -fsSLO https://raw.githubusercontent.com/osergios/karta/main/setup.sh && chmod +x setup.sh
docker compose pull && docker compose up -d
./setup.sh usb      # ή: ./setup.sh cloud
```

Η βάση και οι ρυθμίσεις σας δεν αλλάζουν· ό,τι έχετε στο `.env` συνεχίζει να ισχύει. Μετά:
«Σήμερα» → «Ανανέωση οθόνης». Οδηγίες:
[Αντίγραφα ασφαλείας και επαναφορά](https://github.com/osergios/karta/wiki/Backups).

## Karta 1.2.0: settings in the admin page, backups for years

### New

- **Settings in the admin page** («Ρυθμίσεις» → «Επιχείρηση και σύνδεση με το ΕΡΓΑΝΗ»):
  ΑΦΜ (tax number), branch, the Ergani user (and a user for the Ergani test environment)
  with a **login test**. The password is stored encrypted. Changes apply at once, no restart.
- **Switching mode** (dry run → Ergani test environment → live) from the admin page,
  confirmed by typing the ΑΦΜ, with a login test before the switch.
- **Phone notifications** (ntfy) set up from the admin page, with a test notification.
- **Backups kept for years:** every night, 30 daily, 24 monthly and one per year. A copy
  **on a USB stick** (`./setup.sh usb`) or **encrypted in the cloud** — Google Drive,
  Dropbox, Backblaze B2 (`./setup.sh cloud`), and **restore** with `./setup.sh restore`.
  In the admin page: each night's result, an alert if backups stop, a **backup download**
  and a yearly **punch archive** in Excel.
- **A simpler setup assistant:** it only asks for the address, the admin emails and
  Cloudflare.

### Fixes

- In yes/no questions, a Latin "n" now means no.
- The assistant always installs in `~/karta` and says which folder to rerun it in.
- When Ergani is slow, «Έλεγχος ΕΡΓΑΝΗ» stops after 60″ with a clear message instead of
  "Error 524". Cloudflare errors are explained in Greek.
- «Ωράρια»: Ergani usually gives only the weekly hours, so each day's schedule comes from
  the accountant's timesheet.

### Updating

```bash
cd ~/karta
curl -fsSLO https://raw.githubusercontent.com/osergios/karta/main/setup.sh && chmod +x setup.sh
docker compose pull && docker compose up -d
./setup.sh usb      # or: ./setup.sh cloud
```

Your database and settings stay as they are; whatever is in `.env` keeps working. Then:
«Σήμερα» → «Ανανέωση οθόνης». Guide:
[Backups and restore](https://github.com/osergios/karta/wiki/Backups-EN).
