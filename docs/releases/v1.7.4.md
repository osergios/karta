## Karta 1.7.4: πιο σταθερά αντίγραφα στο cloud

### Διορθώσεις

- **Ένα αργό Google Drive δεν αποτυγχάνει πια το νυχτερινό αντίγραφο.** Η Karta έδινε στη
  σύνδεση με το cloud μόνο ένα λεπτό για να ξεκινήσει· τώρα δίνει πέντε.
- Αν ένα ανέβασμα αποτύχει, η Karta **ξαναδοκιμάζει μετά από μία ώρα** (και κάθε ώρα μέχρι να
  πετύχει), αντί να περιμένει την επόμενη νύχτα.
- Το μήνυμα είναι πλέον στα ελληνικά: «Το cloud άργησε να απαντήσει (συνήθως προσωρινό)».

## Αναβάθμιση

- Από τη σελίδα διαχείρισης («Ενημέρωση τώρα») ή `./setup.sh update`. Τίποτα άλλο.
- Βάση δεδομένων: χωρίς αλλαγές.
- Επιστροφή σε προηγούμενη έκδοση: ασφαλής.

## Karta 1.7.4: steadier cloud backups

### Fixes

- **A slow Google Drive no longer fails the nightly backup.** Karta gave the cloud connection
  only one minute to start; it now gives five.
- If an upload fails, Karta **tries again an hour later** (and every hour until it works),
  instead of waiting for the next night.
- The message is now in plain Greek: «Το cloud άργησε να απαντήσει (συνήθως προσωρινό)».

## Upgrading

- From the admin page («Ενημέρωση τώρα») or `./setup.sh update`. Nothing else.
- Database: no changes.
- Going back to the previous version: safe.
