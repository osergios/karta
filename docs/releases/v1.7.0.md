## Karta 1.7.0: πιο απλό «Σήμερα», χωρίς λειτουργία εκπαίδευσης

### Αλλαγές

- **Η «Λειτουργία εκπαίδευσης» καταργήθηκε.** Το προσωπικό εξασκείται στη **«Δοκιμαστική»**
  λειτουργία: η οθόνη του καταστήματος δουλεύει κανονικά και τίποτα δεν στέλνεται στο ΕΡΓΑΝΗ.
  Μετά, «Ρυθμίσεις» → «Κινήσεις» → «Διαγραφή δοκιμαστικών κινήσεων». Στα «Πρώτα βήματα», η
  «Δοκιμή με το προσωπικό» τσεκάρεται μόνη της με το πρώτο δοκιμαστικό χτύπημα.
- **Το «Σήμερα» δείχνει τη λειτουργία σε μία γραμμή**, με τα ίδια ονόματα όπως στις
  «Ρυθμίσεις», π.χ. «Λειτουργία: Περίοδος προσαρμογής · τίποτα δεν στέλνεται στο ΕΡΓΑΝΗ· η
  αποστολή ξεκινά την Δευτέρα 12 Οκτωβρίου 2026». Χωρίς κουμπί και χωρίς τη μεγάλη παράγραφο·
  ο πίνακας «Πώς τα πάνε» μένει.
- Η κεφαλίδα της σελίδας διαχείρισης γράφει τη λειτουργία με τα ίδια ονόματα («Κανονική
  λειτουργία» αντί για «Παραγωγή ΕΡΓΑΝΗ»).
- Με το απολογιστικό σύστημα, το «Ωράριο καταστήματος» δεν γράφει πια ότι η υπερωρία
  «πρέπει να δηλώνεται στο ΕΡΓΑΝΗ πριν γίνει»: γράφει ότι δηλώνεται απολογιστικά, έως το
  τέλος του επόμενου μήνα.
- Νέες εικόνες και πληρέστερες οδηγίες στο wiki (Έναρξη κανονικής λειτουργίας, Σήμερα,
  Ρυθμίσεις).

## Αναβάθμιση

- Από τη σελίδα διαχείρισης («Ενημέρωση τώρα») ή `./setup.sh update`. Τίποτα άλλο.
- Βάση δεδομένων: χωρίς αλλαγές.
- Επιστροφή σε προηγούμενη έκδοση: ασφαλής.

## Karta 1.7.0: a simpler «Σήμερα», no training mode

### Changes

- **Training mode («Λειτουργία εκπαίδευσης») is removed.** Staff practise in **«Δοκιμαστική»**
  (test) mode: the shop screen works as usual and nothing is sent to Ergani. Afterwards,
  «Ρυθμίσεις» → «Κινήσεις» → «Διαγραφή δοκιμαστικών κινήσεων» (delete test punches). In
  «Πρώτα βήματα» (first steps), «Δοκιμή με το προσωπικό» (trial run with the staff) ticks itself
  off with the first test punch.
- **«Σήμερα» (today) shows the mode in one line**, with the same names as «Ρυθμίσεις», e.g.
  «Λειτουργία: Περίοδος προσαρμογής · τίποτα δεν στέλνεται στο ΕΡΓΑΝΗ· η αποστολή ξεκινά την
  Δευτέρα 12 Οκτωβρίου 2026» (onboarding period: nothing is sent; sending starts on Monday
  12 October 2026). No button and no long paragraph; the «Πώς τα πάνε» table stays.
- The admin page header names the mode the same way («Κανονική λειτουργία» instead of
  «Παραγωγή ΕΡΓΑΝΗ»).
- With the retrospective system, «Ωράριο καταστήματος» (shop hours) no longer says overtime
  must be declared to Ergani before it happens: it says it's declared retrospectively, by the
  end of the next month.
- New screenshots and fuller wiki pages (Going live, Today, Settings).

## Upgrading

- From the admin page («Ενημέρωση τώρα») or `./setup.sh update`. Nothing else.
- Database: no changes.
- Going back to the previous version: safe.
