## Karta 1.7.1: ασφαλής επανασύνδεση στο cloud

### Διόρθωση

- **Μια αποτυχημένη επανασύνδεση στο cloud δεν σβήνει πια τον κωδικό κρυπτογράφησης.** Όταν
  έληγε η πρόσβαση στο cloud και πατούσατε ξανά «Σύνδεση», η Karta έσβηνε πρώτα τη ρύθμιση και
  τον κωδικό από το μηχάνημα· αν η σύνδεση αποτύγχανε, έμεναν μόνο όσα είχατε γράψει σε χαρτί.
  Τα αντίγραφα στο cloud δεν πειράζονταν ποτέ. Τώρα η νέα σύνδεση δοκιμάζεται χωριστά και
  αντικαθιστά την παλιά μόνο αν δουλέψει.
- Η επανασύνδεση κρατά τον **ίδιο κωδικό κρυπτογράφησης** και συνεχίζει στα ίδια αντίγραφα,
  χωρίς να χρειάζεται να τον γράψετε.

## Αναβάθμιση

- Από τη σελίδα διαχείρισης («Ενημέρωση τώρα») ή `./setup.sh update`. Τίποτα άλλο.
- Βάση δεδομένων: χωρίς αλλαγές.
- Επιστροφή σε προηγούμενη έκδοση: ασφαλής.

## Karta 1.7.1: safe cloud reconnect

### Fix

- **A failed cloud reconnect no longer deletes the encryption password.** When cloud access
  expired and you pressed «Σύνδεση» again, Karta first removed the setup and the password from
  the machine; if connecting then failed, only what you had written down was left. The backups
  in the cloud were never touched. Now the new connection is tried separately and replaces the
  old one only if it works.
- Reconnecting keeps the **same encryption password** and carries on with the same backups,
  without you having to type it.

## Upgrading

- From the admin page («Ενημέρωση τώρα») or `./setup.sh update`. Nothing else.
- Database: no changes.
- Going back to the previous version: safe.
