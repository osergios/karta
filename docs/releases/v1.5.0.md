## Karta 1.5.0: ενημερώσεις που γυρίζουν πίσω μόνες τους

### Νέα

- **Ασφαλής ενημέρωση:** αν μια νέα έκδοση δεν ξεκινήσει σωστά μέσα σε δύο λεπτά, η Karta
  επιστρέφει μόνη της στην προηγούμενη, και η σελίδα διαχείρισης γράφει «απέτυχε — επέστρεψε
  στην …». Η έκδοση που τρέχει γράφεται στο `.env` (`KARTA_VERSION`).
- **Πιο προστατευμένο container:** τα αρχεία της εφαρμογής δεν αλλάζουν, χωρίς επιπλέον
  δικαιώματα, με όριο μνήμης, και έλεγχος υγείας (`docker ps` δείχνει «healthy»).
- **Χωρίς tunnel, πίσω από δικό σας reverse proxy:** νέα σελίδα στο wiki με Caddy και nginx.
- **Υπογεγραμμένο image:** ελέγχεται με
  `gh attestation verify oci://ghcr.io/osergios/karta:1.5.0 --owner osergios`.

### Αντίγραφα στο cloud

- Το πρώτο αντίγραφο ανεβαίνει αμέσως με τη σύνδεση, και η σελίδα γράφει αν πέτυχε.
- Καθαρά μηνύματα λάθους: δεν βρέθηκαν αντίγραφα, κλειδωμένα από διακοπή, λάθος κωδικός, ο
  χώρος γέμισε, η πρόσβαση έληξε.
- Ένα αντίγραφο που κόπηκε στη μέση (διακοπή ρεύματος) δεν μπλοκάρει πια τα επόμενα.
- Οι ειδοποιήσεις για τα αντίγραφα κλείνουν μόνες τους όταν λυθεί το πρόβλημα, και ένα πρώτο
  αντίγραφο που δεν έγινε ποτέ έχει δική του ειδοποίηση με την αιτία.

### Τεκμηρίωση

- Τα αντίγραφα στο USB **δεν** είναι κρυπτογραφημένα: φυλάξτε το USB σαν τα κλειδιά του
  καταστήματος.
- Η Karta δουλεύει πάντα σε ώρα Ελλάδας, ό,τι ώρα κι αν έχει ο server.

## Αναβάθμιση

- **Μία φορά** από το μηχάνημα: `cd ~/karta && ./setup.sh update`. Φέρνει το νέο `update.sh`
  (την αυτόματη επιστροφή) και το νέο `docker-compose.yml`. Από εκεί και πέρα, «Ενημέρωση τώρα»
  στη σελίδα διαχείρισης. Αν έχετε αλλάξει μόνοι σας το `docker-compose.yml`, μένει όπως είναι.
- Βάση δεδομένων: αναβαθμίζεται αυτόματα (σχήμα v1)· τίποτα να κάνετε.
- Επιστροφή σε προηγούμενη έκδοση: ασφαλής.

## Karta 1.5.0: updates that go back by themselves

### New

- **Safe updates:** if a new version doesn't start properly within two minutes, Karta goes
  back to the previous one by itself, and the admin page says «απέτυχε — επέστρεψε στην …»
  (failed, went back to …). The running version is written in `.env` (`KARTA_VERSION`).
- **A better protected container:** the app files can't change, no extra privileges, a memory
  limit, and a healthcheck (`docker ps` shows "healthy").
- **Without the tunnel, behind your own reverse proxy:** a new wiki page with Caddy and nginx.
- **A signed image:** check it with
  `gh attestation verify oci://ghcr.io/osergios/karta:1.5.0 --owner osergios`.

### Cloud backups

- The first backup is uploaded right when you connect, and the page says whether it worked.
- Clear error messages: no backups found, locked by an interruption, wrong password, the cloud
  is full, access expired.
- A backup cut off half-way (a power cut) no longer blocks the next ones.
- Backup alerts close by themselves once the problem is gone, and a first backup that never
  worked has its own alert with the reason.

### Documentation

- USB copies are **not** encrypted: keep the stick safe, like the shop's keys.
- Karta always works in Greek time, whatever the server's time is.

## Upgrading

- **Once** on the machine: `cd ~/karta && ./setup.sh update`. It brings the new `update.sh`
  (the automatic way back) and the new `docker-compose.yml`. After that, «Ενημέρωση τώρα» in
  the admin page. A `docker-compose.yml` you changed yourself stays as it is.
- Database: upgraded automatically (schema v1); nothing to do.
- Going back to the previous version: safe.
