## Karta 1.1.0: εγκατάσταση με οδηγό

### Νέα

- **Οδηγός ρύθμισης (`./setup.sh`).** Ερωτήσεις στα ελληνικά, και ο οδηγός κάνει τα υπόλοιπα:
  - ελέγχει το ΑΦΜ και **δοκιμάζει τη σύνδεση στο ΕΡΓΑΝΗ** (μόνο ανάγνωση)·
  - με ένα κλειδί API του Cloudflare φτιάχνει **αυτόματα** το tunnel, τη διεύθυνση και την
    προστασία της σελίδας διαχείρισης·
  - ρυθμίζει τις ειδοποιήσεις στο κινητό (ntfy) με δοκιμαστική ειδοποίηση·
  - γράφει το `.env`, ξεκινά την Karta και ρυθμίζει **αυτόματα αντίγραφα ασφαλείας** κάθε βράδυ.
  Χρειάζεται μόνο Docker, που μπορεί και να το εγκαταστήσει.
- **`./setup.sh check`:** ελέγχει ρυθμίσεις, ΕΡΓΑΝΗ, Cloudflare, ότι η Karta απαντά στη
  διεύθυνσή σας, και **προειδοποιεί αν η σελίδα διαχείρισης δεν είναι προστατευμένη**.
- **«Πρώτα βήματα»** στην καρτέλα «Σήμερα»: λίστα με όσα χρειάζεται μια νέα εγκατάσταση, που
  τσεκάρεται μόνη της, με κουμπί «Πάμε» σε κάθε βήμα.
- **«Δοκιμαστική ειδοποίηση»** στο κινητό από τη σελίδα διαχείρισης.
- Νέος οδηγός: [Εύκολη εγκατάσταση, βήμα προς βήμα](https://github.com/osergios/karta/wiki/Easy-Installation).

### Ενημέρωση

```bash
cd ~/karta
curl -fsSLO https://raw.githubusercontent.com/osergios/karta/main/setup.sh && chmod +x setup.sh
docker compose pull && docker compose up -d
```

Η βάση και οι ρυθμίσεις σας δεν αλλάζουν. Μετά: «Σήμερα» → «Ανανέωση οθόνης».

## Karta 1.1.0: guided installation

### New

- **Setup assistant (`./setup.sh`).** Questions in Greek, and the assistant does the rest:
  - checks the ΑΦΜ and **tests the Ergani login** (read‑only);
  - with a Cloudflare API key it creates the tunnel, the address and the admin page protection
    **automatically**;
  - sets up phone notifications (ntfy) with a test notification;
  - writes `.env`, starts Karta and sets up **automatic nightly backups**.
  It only needs Docker, which it can also install.
- **`./setup.sh check`:** checks the settings, Ergani, Cloudflare, that Karta answers on your
  address, and **warns if the admin page isn't protected**.
- **«Πρώτα βήματα» (first steps)** on the «Σήμερα» tab: a checklist of what a new installation
  needs, ticked off automatically, with a «Πάμε» button for each step.
- **Test phone notification** from the admin page.
- New guide: [Easy installation, step by step](https://github.com/osergios/karta/wiki/Easy-Installation-EN).

### Updating

```bash
cd ~/karta
curl -fsSLO https://raw.githubusercontent.com/osergios/karta/main/setup.sh && chmod +x setup.sh
docker compose pull && docker compose up -d
```

Your database and settings don't change. Then: «Σήμερα» → «Ανανέωση οθόνης».
