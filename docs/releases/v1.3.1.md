## Karta 1.3.1

### Βελτίωση

- **Ελαφρύτερος έλεγχος για ενημέρωση:** το `update.sh` κοιτάζει κάθε 2 λεπτά (αντί για κάθε
  λεπτό) και μόνο διαβάζει, εκτός αν έχει ζητηθεί ενημέρωση· σημάδι ότι λειτουργεί γράφεται
  μία φορά τη μισή ώρα. Λιγότερη δουλειά για το μηχάνημα και λιγότερες εγγραφές στην κάρτα
  SD του Raspberry Pi.

### Ενημέρωση

«Ρυθμίσεις» → «Έκδοση και ενημέρωση» → «Ενημέρωση τώρα», ή από το μηχάνημα:

```bash
cd ~/karta
curl -fsSLO https://raw.githubusercontent.com/osergios/karta/main/setup.sh && chmod +x setup.sh
./setup.sh update
```

## Karta 1.3.1

### Improvement

- **A lighter update check:** `update.sh` looks every 2 minutes (instead of every minute)
  and only reads, unless an update was requested; the "alive" mark is written once every
  half hour. Less work for the machine and fewer writes to the Raspberry Pi's SD card.

### Updating

«Ρυθμίσεις» → «Έκδοση και ενημέρωση» → «Ενημέρωση τώρα», or on the machine:

```bash
cd ~/karta
curl -fsSLO https://raw.githubusercontent.com/osergios/karta/main/setup.sh && chmod +x setup.sh
./setup.sh update
```
