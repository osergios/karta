## Karta 1.2.1

### Διόρθωση

- **Αντίγραφο στο cloud:** οι οδηγίες στη σελίδα διαχείρισης δείχνουν πλέον την ακριβή εντολή
  για τα Windows, `.\rclone.exe authorize "drive"` (το PowerShell δεν τρέχει προγράμματα από
  τον τρέχοντα φάκελο χωρίς το `.\`), και `./rclone authorize "drive"` για Mac / Linux.

### Ενημέρωση

```bash
cd ~/karta && docker compose pull && docker compose up -d
```

## Karta 1.2.1

### Fix

- **Cloud backup:** the admin page instructions now show the exact Windows command,
  `.\rclone.exe authorize "drive"` (PowerShell doesn't run programs from the current folder
  without `.\`), and `./rclone authorize "drive"` for Mac / Linux.

### Updating

```bash
cd ~/karta && docker compose pull && docker compose up -d
```
